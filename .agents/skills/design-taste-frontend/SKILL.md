# Anti-AI Slop Frontend Design Guidelines

This skill enforces intentional, high-taste frontend design choices to eliminate AI boilerplate ("AI slop") and create distinct, memorable visual craft.

## 1. Eliminate Cliché AI-isms & Tropes
- **No Boilerplate Copy:** Eliminate cliché AI phrases like "Connection Established", "My inbox is always open...", "Passionate developer crafting digital experiences", "Welcome to my digital corner", or overly dramatic terminal commands like `whoami` / `ping contact` on every block.
- **No Monotonous Card Layouts:** Do not wrap every single section in the exact same card or window container. Vary layout densities, asymmetry, callouts, and structural grids.
- **No Generic Color Schemes:** Avoid default Tailwind blues/greens or flat grey backgrounds with a single primary accent applied everywhere indiscriminately. Use rich HSL/OKLCH color scales with intentional contrast layers, deep dark tones `#090d16` or dark slate with amber/copper accents.

## 2. Typography & Visual Hierarchy
- **Intentional Font Pairing:** Combine a strong display font for section headings with a crisp monospace accent for technical details and clean sans-serif for body text.
- **Expressive Scale Contrast:** Use bold contrast between macro section titles (e.g. 3xl–5xl) and compact, dense meta labels (10px–12px uppercase tracked).
- **Rhythm & Spacing:** Avoid uniform vertical gaps; use asymmetric spacing rhythm (e.g., wider gaps before major sections, compact groupings within sub-components).

## 3. High-Craft Micro-Details
- **Depth & Materials:** Use subtle borders (`rgba(255,255,255,0.08)`), frosted glass layers, subtle noise/grid background textures, and status pills.
- **Interactive Feedback:** Fast, tactile hover states with subtle border highlights, smooth color transitions, and crisp focus rings.
- **Authentic Developer Persona:** Present real skills, genuine projects, live CLI-like output or clean status dashboards with authentic details for Linux Administration, Backend Dev, and Containerization.
