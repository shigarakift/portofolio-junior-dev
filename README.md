# Vibe Code - Portfolio Dev

This is a modern web development portfolio built with [Next.js](https://nextjs.org/) and styled with [Tailwind CSS](https://tailwindcss.com/). It features smooth scrolling with [Lenis](https://lenis.darkroom.engineering/) and beautiful animations with [Framer Motion](https://www.framer.com/motion/).

## Features

- **Next.js 16** (App Router)
- **Tailwind CSS** for responsive styling
- **Framer Motion** for micro-animations and page transitions
- **Lenis** for smooth, customized scrolling
- **Lucide React** & **React Icons** for clean, scalable vector graphics

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
